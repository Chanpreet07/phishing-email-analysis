# Offline Phishing Lab
# 🕵️‍♂️ Phishing Email Analysis Lab

## 📌 Overview
This project demonstrates a **safe offline lab** for analyzing phishing emails.  
All experiments are **controlled and offline**, so no real users are affected.

---

## 🛠️ Tools Used
- Thunderbird (Email client)  
- Ubuntu  
- Python3 (for offline landing pages)  
- HTML (Email templates and landing pages)  
- Screenshot tool (for capturing email view)  

---

## ⚙️ Setup
1. Install **Virtual machine and run ubuntu** 
2. Install **Thunderbird** on Ubuntu.  

---

## 📧 Email Analysis
- Open `.eml` or `.html` files in Thunderbird.  
- Check **headers** for sender information, subject, and routing.  
- Analyze **links and HTML content** for suspicious elements.  
- Simulate **tracking pixels** in emails using offline images.
